# Вокальная студия «Орфей»

Современный лендинг для вокальной студии с формой обратной связи, расписанием, отзывами и информацией о преподавателях.

## Стек

- **HTML5** — семантическая разметка
- **CSS3** — адаптивный дизайн (mobile-first), Flexbox, Grid, анимации
- **JavaScript (ES6+)** — слайдер отзывов, модальное окно, бургер-меню, Intersection Observer

## Как запустить

### GitHub Pages (рекомендуется)

1. Создайте репозиторий `Natali` на GitHub
2. Загрузите все файлы проекта в корень репозитория
3. Перейдите в Settings → Pages → Source: Deploy from branch → main → / (root) → Save
4. Сайт будет доступен по адресу: `https://<ваш-username>.github.io/Natali/`

### Локально

Просто откройте `index.html` в любом современном браузере. Сервер не требуется.
